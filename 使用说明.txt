打开方式：解压完整文件夹后，用 Chrome 或 Edge 打开 index.html。请保留 assets 文件夹与网页文件的相对位置。

已完成：
1. 第一次点击：播放透明撕胶带视频，展示斜视打开箱子，弹出原版标题 PNG 及 FROM / TO。
2. 再次点击：过渡到俯视箱子。五组独立物件支持悬停/键盘聚焦放大，只有唱片机点击跳转。
3. 唱片转场与音乐：点击唱片机启动 Come Around Me，唱片页控制按钮位于黑胶旁，手机窄屏放在唱片上方留白处；进入项目后按钮移到顶部，继续保持进度及暂停状态。歌曲循环播放。
4. 五个项目取消内容图片点击放大，替换运营活动设计和科大讯飞品牌线下物料设计首图；保留个人信息放大阅读。
5. 新增抱礼盒 IP 的节奏弹跳、喇叭 IP 漂浮和声波、翠丝/巴斯/胡迪分别起伏摇摆。角色在可视区域内播放，受暂停动效按钮控制。

实现说明：
- 开箱视角采用图片缩放和叠化，并非三维箱盖动画。
- 奔跑效果为整体弹跳与轻微倾斜，不是双腿交替的骨骼动画。
- 使用 ImageGen 补齐箱内、角色背后背景，并清理喇叭 IP 的白色残留；补出的隐藏背景和清理后的 IP 边缘会与原图有细微差异。
- 页面保留原网站字体配置；无法加载在线字体时使用本地系统字体。
- 当前是本地网页交付，未发布到公网。
